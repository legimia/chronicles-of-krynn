# Chronicles of Krynn Tools

A central directory of tools for Chronicles of Krynn, maintained by [legimia](https://github.com/legimia).

## Find a tool

| Tool | What it does | Get started |
| --- | --- | --- |
| [Krynn Color Text Editor](https://github.com/legimia/ansii-editor) | Write colored descriptions with a 256-color palette, foreground and highlight colors, two- or three-color gradients, paint brushes, an eyedropper, undo/redo, and synchronized visual/code views. Export Krynn color markup with 80-column color refreshes or save editable JSON projects. | Download the HTML file and open it in your browser. |
| [Krynn Crafting Studio](https://github.com/legimia/crafting-studio) | Plan recipes and materials, configure enhancements, catalysts, up to six eligible bonus slots, and instrument properties. Edit colored item descriptions, generate crafting commands, review validation warnings, and save or restore plans as JSON. | Download the standalone HTML file and open it in your browser. |
| [Krynn Native UI for Mudlet](https://github.com/legimia/mudlet-ui) | Add an in-game sidebar with player, quest, group, room, and affects panels; HP/PSP/movement/XP gauges; ASCII and graphical maps; room action buttons; filtered chat history; and adjustable layout dimensions. | Download the `.mpackage` and install it in your Krynn profile through Mudlet's Package Manager. |

## Which one should I use?

- **Writing a colored description?** Start with the Color Text Editor.
- **Planning a crafted item and its commands?** Use Crafting Studio, which also includes a visual description editor.
- **Playing in Mudlet and want a richer interface?** Install Krynn Native UI.

Each tool has its own repository, detailed README, and issue tracker. Open the relevant repository above for downloads, instructions, and limitations.
